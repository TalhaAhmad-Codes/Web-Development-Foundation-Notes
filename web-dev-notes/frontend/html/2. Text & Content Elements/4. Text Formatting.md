# ✔️ Text Formatting in HTML

HTML provides several tags for formatting text.
Some provide **semantic meaning**, while others are purely **visual**.

---

## `<strong>` vs `<b>`

### `<strong>` (Semantic Importance)

* Indicates **strong importance**
* Screen readers emphasize it
* Good for SEO

```html
<p>This is <strong>important</strong> text.</p>
```

### `<b>` (Visual Bold Only)

* Makes text bold
* No semantic meaning

```html
<p>This is <b>bold</b> text.</p>
```

✔ **Best Practice:** Prefer `<strong>` for meaningful emphasis.

---

## `<em>` vs `<i>`

### `<em>` (Semantic Emphasis)

* Indicates emphasis
* Screen readers change tone

```html
<p>This is <em>very important</em>.</p>
```

### `<i>` (Visual Italic Only)

* Italic styling only
* Often used for icons or technical terms

```html
<p>This is <i>italic</i> text.</p>
```

✔ **Best Practice:** Prefer `<em>` when emphasis matters.

---

## `<mark>`

### Purpose

Highlights text.

```html
<p>This is <mark>highlighted</mark> text.</p>
```

Used for:

* Search results
* Important notes

---

## `<small>`

### Purpose

Represents smaller or secondary text.

```html
<p>Main content <small>terms & conditions apply</small></p>
```

Commonly used for:

* Copyright
* Legal text
* Side notes

---

## `<del>` and `<ins>`

### `<del>` (Deleted Text)

Shows removed content.

```html
<p>Price: <del>$100</del> $80</p>
```

### `<ins>` (Inserted Text)

Shows added content.

```html
<p>New feature: <ins>Dark Mode</ins></p>
```

Used for:

* Version changes
* Content updates

---

## `<sub>` and `<sup>`

### `<sub>` (Subscript)

```html
<p>H<sub>2</sub>O</p>
```

Result: H₂O

### `<sup>` (Superscript)

```html
<p>2<sup>3</sup> = 8</p>
```

Result: 2³ = 8

Used for:

* Mathematical formulas
* Chemical formulas
* Footnotes

---

## Semantic vs Visual Tags (Important)

| Semantic   | Visual |
| ---------- | ------ |
| `<strong>` | `<b>`  |
| `<em>`     | `<i>`  |

✔ Use **semantic tags** when meaning matters
✔ Use CSS for pure styling

---

## Best Practice Summary

* Prefer semantic tags (`<strong>`, `<em>`)
* Do not use formatting tags for layout
* Use CSS for design control
* Choose tags based on meaning, not appearance

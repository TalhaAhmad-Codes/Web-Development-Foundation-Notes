# ✔️ Quotations in HTML

HTML provides specific elements to represent **quoted content and references**.

---

## `<blockquote>`

### Purpose

Represents a **long quotation** from another source.

* Block-level element
* Usually displayed with indentation

### Example

```html
<blockquote>
    The only way to do great work is to love what you do.
</blockquote>
```

### With `cite` Attribute

```html
<blockquote cite="https://example.com/article">
    The only way to do great work is to love what you do.
</blockquote>
```

`cite` provides the source URL (not visible by default).

✔ Used for:

* Articles
* Testimonials
* External references

---

## `<q>`

### Purpose

Represents a **short inline quotation**.

* Inline element
* Browser automatically adds quotation marks

### Example

```html
<p>He said <q>HTML is the foundation of the web</q>.</p>
```

✔ Used inside paragraphs.

---

## `<cite>`

### Purpose

Represents the **title of a work** (not the author).

### Example

```html
<p>My favorite book is <cite>Clean Code</cite>.</p>
```

Can also be used with blockquote:

```html
<blockquote>
    Simplicity is the soul of efficiency.
    <footer>
        — <cite>Austin Freeman</cite>
    </footer>
</blockquote>
```

🧠 Note:
`<cite>` is for:

* Books
* Articles
* Movies
* Research papers
* Document titles

---

## Quick Comparison

| Tag            | Type        | Use Case      |
| -------------- | ----------- | ------------- |
| `<blockquote>` | Block-level | Long quotes   |
| `<q>`          | Inline      | Short quotes  |
| `<cite>`       | Inline      | Title of work |

---

## Best Practices

* Use `<blockquote>` for large quoted sections
* Use `<q>` for inline quotes
* Use `<cite>` for referencing titles
* Do not use these for styling purposes

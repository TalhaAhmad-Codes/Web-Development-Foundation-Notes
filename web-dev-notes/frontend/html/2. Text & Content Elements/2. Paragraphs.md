# Paragraphs (`<p>`)

The `<p>` element is used to define a **paragraph of text** in HTML.

---

## Basic Syntax

```html
<p>This is a paragraph.</p>
```

* `<p>` → Opening tag
* Text → Content
* `</p>` → Closing tag

---

## Example

```html
<h1>About HTML</h1>

<p>HTML is used to structure web pages.</p>

<p>It works together with CSS and JavaScript.</p>
```

Each `<p>` creates a **separate block of text**.

---

## Default Behavior

* Paragraphs are **block-level elements**
* Browser automatically adds:

  * Margin above
  * Margin below

You do not need to add `<br>` for spacing between paragraphs.

---

## Line Break Inside Paragraph

To break a line inside a paragraph:

```html
<p>
    This is line one.<br>
    This is line two.
</p>
```

Use `<br>` only for **small line breaks**, not for spacing.

---

## Important Rules

✔ Always close `<p>`
✔ Do not nest block elements inside `<p>`

❌ Incorrect:

```html
<p>
    <div>Invalid</div>
</p>
```

✔ Correct:

```html
<div>
    <p>Valid structure</p>
</div>
```

---

## Paragraph vs Headings

* `<p>` → Regular content
* `<h1>–<h6>` → Titles & section structure

Do not use headings for normal text.

---

## In Real Projects

### Razor Example

```html
<p>@Model.Description</p>
```

Paragraphs are commonly used to display:

* API data
* Blog content
* Product descriptions
* User messages

---

## Quick Summary

* `<p>` defines a paragraph
* It is a block-level element
* Always close it
* Use `<br>` only for small line breaks
* Do not misuse for layout

# Line Breaks (`<br>`) vs Horizontal Rules (`<hr>`)

Both `<br>` and `<hr>` are **self-closing elements**, but they serve very different purposes.

---

## `<br>` — Line Break

### Purpose

Creates a **single line break** inside text.

### Example

```html
<p>
    Line one<br>
    Line two
</p>
```

✔ Used for:

* Addresses
* Poems
* Small text formatting

❌ Not for spacing layout

---

## `<hr>` — Horizontal Rule

### Purpose

Represents a **thematic break** between sections.

### Example

```html
<h2>Section One</h2>
<p>Content...</p>

<hr>

<h2>Section Two</h2>
<p>More content...</p>
```

✔ Used to:

* Separate topics
* Indicate content shift
* Improve readability

---

## Key Differences

| Feature          | `<br>`             | `<hr>`                       |
| ---------------- | ------------------ | ---------------------------- |
| Type             | Line break         | Section divider              |
| Visual Output    | Moves to next line | Draws horizontal line        |
| Semantic Meaning | None               | Indicates content separation |
| Use Case         | Inside text        | Between sections             |

---

## Important Notes

* Both are **self-closing**
* Neither wraps content
* Should not be used for layout spacing
* Styling should be handled using CSS

---

## Quick Summary

* `<br>` → Breaks line
* `<hr>` → Separates sections
* Use meaningfully, not for design

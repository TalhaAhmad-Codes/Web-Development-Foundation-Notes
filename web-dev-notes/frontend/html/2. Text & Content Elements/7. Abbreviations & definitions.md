# Abbreviations & Definitions (`<abbr>`, `<dfn>`)

These elements provide **semantic meaning** for abbreviations and defined terms.

---

## `<abbr>` — Abbreviation

### Purpose

Represents an abbreviation or acronym.

### Common Usage (with `title` attribute)

```html
<p>
    <abbr title="HyperText Markup Language">HTML</abbr> is used to build web pages.
</p>
```

* `title` shows full meaning on hover
* Improves accessibility
* Helpful for screen readers

✔ Used for:

* HTML
* CSS
* API
* URL
* ASP.NET

---

## `<dfn>` — Definition

### Purpose

Represents the **defining instance** of a term.

```html
<p>
    <dfn>HTML</dfn> is a markup language used to structure web content.
</p>
```

Used when introducing a term for the **first time**.

---

## Combined Example

```html
<p>
    <dfn><abbr title="HyperText Markup Language">HTML</abbr></dfn>
    is the standard language for creating web pages.
</p>
```

---

## Quick Comparison

| Tag      | Purpose                 |
| -------- | ----------------------- |
| `<abbr>` | Abbreviation or acronym |
| `<dfn>`  | Defines a new term      |

---

## Best Practices

* Always use `title` with `<abbr>`
* Use `<dfn>` only when defining a term
* Do not use for styling
* Helps with SEO and accessibility

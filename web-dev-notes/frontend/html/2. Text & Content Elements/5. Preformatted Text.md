# Preformatted Text (`<pre>`)

The `<pre>` element displays text **exactly as written in the HTML file**.

It preserves:

* Spaces
* Line breaks
* Indentation

---

## Basic Example

```html
<pre>
Line 1
    Line 2 (indented)
        Line 3
</pre>
```

The browser will render the spacing exactly as typed.

---

## Why `<pre>` is Useful

* Displaying code snippets
* Showing configuration files
* Preserving ASCII diagrams
* Formatting structured text

---

## Common Use with `<code>`

```html
<pre>
<code>
int x = 10;
Console.WriteLine(x);
</code>
</pre>
```

`<code>` adds semantic meaning (represents code),
`<pre>` preserves formatting.

---

## Default Behavior

* Rendered in **monospace font**
* Block-level element
* Preserves whitespace

---

## Important Notes

* Avoid using `<pre>` for layout purposes
* Use it only when whitespace preservation is required
* Large content inside `<pre>` may affect readability

---

## Quick Summary

* `<pre>` preserves formatting
* Useful for code and structured text
* Often combined with `<code>`
* Not meant for styling layout
